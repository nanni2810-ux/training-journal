# Metabolic Conditioning Timer TV

Timer HTML ottimizzato per TV/monitor 16:9 in orizzontale, senza scorrimento della pagina.

Workout:
- 1:00 FAST / 1:00 REST
- 0:45 FAST / 0:45 REST
- 0:30 FAST / 0:30 REST
- 0:45 FAST / 0:45 REST
- 1:00 FAST / 2:00 REST
- repeat

Apri `metabolic-conditioning-tv/index.html` in un browser moderno e premi AVVIA per abilitare anche l'audio.
